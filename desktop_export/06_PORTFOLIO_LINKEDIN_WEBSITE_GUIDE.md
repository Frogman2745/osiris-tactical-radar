# OSIRIS Portfolio, Résumé, and LinkedIn Copy

Verification below reflects the current local release check on October 3, 2026.

## LinkedIn post

I built OSIRIS, a public-source React and TypeScript portfolio simulation that brings a Canvas-based wildfire aviation scenario map and an interactive DAG workflow console into one interface.

The project includes ten-category vector symbology, aircraft and incident dossiers, configurable pipeline stages, WebSocket collaboration, predictive scenario views, failure injection, JSON export, and an in-app documentation hub.

The most important engineering correction was provenance: every aircraft track, incident, base allocation, weather value, turnaround metric, and compute reading is explicitly labeled synthetic. OSIRIS is not connected to CAL FIRE, USFS, DoD, CAD, AFF, or IRWIN, and its 16.5/20-minute values are configurable scenario parameters—not universal airtanker-turnaround mandates.

Current verification: 30/30 Vitest tests passed across three suites, TypeScript completed with zero errors, and the Vite production build succeeded. A Vite bundle-size advisory remains for the largest generated chunk.
